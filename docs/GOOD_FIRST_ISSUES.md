# Good first contributions — fictional form

These are **scoped ideas**, not promises of open assignments or independently verified defects. Look at current issues before proposing a duplicate.

1. **Draft restore boundary:** add a new `tests/checklist.test.mjs` case for a versioned draft that is nearly 2 KB, proving an oversized/malformed draft preserves current form state. Acceptance: deterministic assertion and `npm test`.
2. **Keyboard error focus:** try invalid quantity on a narrow browser and propose a focused `tests/browser_form.py` assertion that the error summary receives focus. Acceptance: an actual failing reproducer followed by a browser test; no claims about screen readers.
3. **Honest feedback copy:** clarify the fictional demo's inline guidance for versioned local draft restore and download without collecting personal data. Acceptance: unchanged model behavior and a screenshot or browser description of the specific improvement.

Use the issue form for an exact reproduction and avoid submitting private research or personal information. Changes to the core model require both valid and invalid input tests.
