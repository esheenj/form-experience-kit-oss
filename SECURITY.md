# Security policy

This is a dependency-free educational form with no production account service, backend or user data. Never enter or attach real personal or confidential content.

For suspected security issues, prefer GitHub's **Security → Advisories → Report a vulnerability** private reporting path if it is enabled for this repository. If private reporting is not available, do not post secrets, exploit payloads or identifying information in a public issue. Request a safe private contact route first.

The maintainer does not promise a response timeframe or production security support. Public PR/issue text is untrusted and does not authorize access to private systems.
